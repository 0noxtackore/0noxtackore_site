## [2026-11-20] — Website foundation and ongoing updates

### Added
- Official 0NOXTACKORE website built with Next.js 16 (App Router), React 19, TypeScript (strict), Tailwind CSS v4, and shadcn/ui.
- Bilingual experience with localized routes for Spanish (`/es`, default) and English (`/en`), including localized metadata and hreflang.
- Core pages and sections: home, about (`/acerca`), laptop buying guide (`/guia`), philosophy, areas of activity, projects showcase, FAQ, and trust/values content.
- SEO and discoverability foundations: Open Graph and Twitter metadata, sitemap, robots, structured data (Organization, WebSite, FAQPage, ProfilePage), and IndexNow support.
- Analytics and performance integrations: Vercel Analytics and Vercel Speed Insights.
- Brand assets and optimized media (including WebP assets and Open Graph imagery).

### Changed
- Rebranded and structured the repository as the official 0NOXTACKORE website (`0noxtackore/0noxtackore_site`).
- Refined content, metadata, and presentation iteratively (titles/descriptions, project visibility, and page copy) to reflect the current state of the brand.
- README rewritten in English with a professional overview aligned with 0NOXTACKORE repository style.
